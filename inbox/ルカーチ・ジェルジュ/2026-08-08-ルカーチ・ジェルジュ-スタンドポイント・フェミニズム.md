## Full Text

スタンドポイント・フェミニズム（英: Standpoint feminism）は、フェミニスト社会科学は女性、あるいは特定の女性集団の立場（スタンドポイント）から実践されるべきだとする理論である。パトリシア・ヒル・コリンズやドロシー・スミス（ドロシー・E・スミス）といった一部の研究者は、女性の方が世界のある側面をよりよく理解する備えを持っていると論じる。フェミニスト（あるいは女性の）スタンドポイント認識論は、男性の経験に加えて、また時には男性の経験の代わりに、女性の経験を出発点とすることを提唱する。


== 概観 ==
女性運動がまだ初期段階にあった頃、カリフォルニア大学バークレー校で教鞭を執っていたドロシー・スミスは、女性研究者たちの経験に注目し、彼女たちの人生史について問い始めた。カール・マルクスから影響を受けたフェミニストとして、スミスは「女性のための社会学（a sociology for women）」の構築へと関心を向けていった。彼女はフェミニスト・スタンドポイント理論を創始し、女性たちの日常世界からの視点、そして女性たちが自らの世界を社会的に構築するその仕方を探究した。1983年にナンシー・ハートソックが理論化したように、スタンドポイント・フェミニズムはマルクス主義に基盤を置いている。ハートソックは、フェミニストのスタンドポイントはマルクスの経験理解から築くことができ、また家父長的な諸理論を批判するために用いうる、と論じた。したがって、フェミニストのスタンドポイントは、女性の知識を軽んじているとスタンドポイント・フェミニストが述べる社会における構造的な抑圧を検討するために不可欠なものである。スタンドポイント・フェミニズムは、ほぼすべての社会において女性の人生や役割が男性のそれと大きく異なっているために、女性は異なる種類の知識を保持していると主張する。従属的な集団に置かれているという位置ゆえに、女性は既存の男性中心的な通念とは異なる、あるいはそれに挑戦するような仕方で世界を見て理解することができる。
スタンドポイント・フェミニズムは、複数のフェミニスト認識論を統合するものである。スタンドポイント・フェミニストの理論家たちは、社会科学および自然科学における支配的な通説的認識論を批判しつつ、フェミニスト的知識の一貫性を擁護しようと試みる。
当初、フェミニスト・スタンドポイント理論は、性別による労働分業のなかでの女性の位置づけを扱っていた。ダナ・ハラウェイのようなスタンドポイント理論家たちは、スタンドポイント理論の見かけ上の相対主義に対抗するものとして、「状況づけられた知識（situated knowledge）……という観念」としてスタンドポイントを提示しようとした。
この理論は、権力に焦点を当てる点と、権力を握る者たちによって生み出され、伝えられ、押し付けられる覇権的な現実、とりわけ「本質的な真理」という観念に挑戦する点で、潜在的に急進的な帰結を持つと考えられている。


== スタンドポイントの確立 ==
フェミニスト・スタンドポイント理論家たちのあいだでは、スタンドポイントとは単に「女性であるという事実」によって占められる視点なのではないという合意がある。視点（パースペクティブ）が自らの社会的・歴史的な位置の事実として占められるものであり、それがスタンドポイントを立ち上げる出発点となりうるのに対し、スタンドポイントとは、科学と政治の双方を要求する集団的な政治闘争の経験を通じて獲得されるものである。支配者と被支配者のいずれもが視点を占めているが、被支配者の方がはるかにスタンドポイントを達成しやすい位置に置かれている。とはいえこれは、周縁化されていない視点を占める者たちが、権力構造や認識的生産の影響についての共有された批判的意識に到達する助けとなりえない、ということを意味するわけではない。たとえば、通説的な科学研究の多くは、女性を自らの現実から切り離す男性中心的な世界観を通じて理解される知識を生み出している。こうした闘争を通じてのみ、われわれは不正な社会秩序が作り出す見せかけの下に隠された、この社会秩序が実際にはどのように構築され維持されているかという現実を見始めることができる。この闘争の必要性は、フェミニストのスタンドポイントは、誰もが単に主張することによって手にできるものではないことを強調するものである。それは達成物である。この点でスタンドポイントは、誰もが「目を開けば」得られる視点とは異なる。

== ブラック・フェミニズム ==
ブラック・フェミニスト思想は、アフリカ系ディアスポラの黒人女性の、および黒人女性のためのスタンドポイントを明確に表現する、アイデア、著作、芸術の集積である。ブラック・フェミニスト思想は、黒人女性を、人種、民族、ジェンダー、階級、性的指向の交差的な過程が黒人女性の個人的および集団的意識、自己定義、行為を形づくる、アメリカ合衆国の社会関係における「ある場所」に存在する固有の集団として描く。スタンドポイント理論の一つとして、ブラック・フェミニスト思想は、アイデンティティを、歴史的文脈の内部にある、有機的で流動的、相互依存的、複数的、そして動的な、社会的に構築された「場所」として概念化する。ブラック・フェミニスト思想は、奴隷制、反リンチ運動、人種隔離、公民権運動およびブラック・パワー運動、性の政治、資本主義、家父長制と黒人女性が結びついてきた歴史的経験に根ざしている。現代のブラック・フェミニスト思想の特徴的な信条には次のものがある。(1) 自己執筆（self-authorship）と、部分的で従属的な知識の正当化とが、黒人女性の、および黒人女性による、独自かつ多様なスタンドポイントを表すという信念。(2) 複数の抑圧を経験した黒人女性の体験は、黒人男性および白人女性のそれとは異なるニーズ、期待、イデオロギー、問題をもたらすということ。(3) ブラック・フェミニスト意識は、常に進化を続ける概念であるということ。ブラック・フェミニスト思想は、黒人女性が知識の担い手として立ち現れつつある力を示している。アフリカ系アメリカ人の女性を、人種、ジェンダー、階級の抑圧に立ち向かう自己定義的・自己依拠的な個人として描くことによって、アフロセントリックなフェミニスト思想は、抑圧された人々のエンパワーメントにおいて知識が果たす重要性を語りかける。ブラック・フェミニスト思想を際立たせる特徴の一つは、個人の意識の変革と、政治・経済制度の社会的変革の双方が、社会変革に不可欠な要素を成すのだと主張する点にある。この双方の次元を変えるために、新しい知識は重要である。
ティナ・カンプトは著書『Other Germans』のなかで、スタンドポイント理論を用いて、アフロ・ドイツ人であるハンス・ハウクの物語を検討している。
パトリシア・ヒル・コリンズによって最初に導入されたブラック・フェミニストのスタンドポイントは、社会の従属集団において類似した視点を持つ者たちの集合的な知恵として知られる。コリンズは、抑圧された集団の意識について主要な二つの解釈を提示している。

第一の解釈は、抑圧されている者たちは支配集団と自己同一化しているため、自らの抑圧について有効な自己統治的な解釈を持たない、というものである。
第二のアプローチは、従属者は自分たちより上位の者たちより「人間らしさが劣る」と想定されており、そのために自らの経験を理解し語る能力に乏しいとされている、というものである。黒人女性たちが共通の経験を持ちうるとしても、それはすべての黒人女性が互いに同じ思考を発達させていることを意味するわけではない。
ブラック・フェミニスト・スタンドポイント理論の目的は、こうした周縁化された集団に対する意識を高め、社会における彼女たちの位置を改善する方法を提示することにある。
一部で共通点はあるものの、ブラック・フェミニスト・スタンドポイント理論は、ドロシー・スミスおよびナンシー・ハートソックによるスタンドポイント理論の原型とは多くの相違を持つ。ブラック・フェミニスト・スタンドポイント論は、ある個人または社会の他集団についての知識は、彼女らが社会において占めてきた歴史的位置に関連する複数の要因から得られる、と論じる。黒人女性は、他者を異なる視点から表象する代替的な立場を提供する。フェミニスト・スタンドポイント理論は、抑圧された他の女性集団の見方を歓迎することによって、女性の多様性を認めることを目指す。
特権的な社会集団に属する者たちとは異なり、黒人女性は、最も抑圧された者から最も特権的な者まで、あらゆる立場の者についての知識にアクセスすることができる。これは、支配集団に属する者たちは抑圧される集団と同じかたちで抑圧を経験しないため、抑圧のある種の現実がその者たちには不可視となっているためである。特権集団は、自分たちの行為が従属集団にどのような影響を及ぼしうるかについて、まったく気づいていないことがある。他方で黒人女性は、直接の経験からより優れた視点（異なるスタンドポイント）を持っており、社会の他の周縁化された集団を助けるための示唆を提供することができる。この黒人女性のスタンドポイントは「二重化された意識（bifurcated consciousness）」、すなわち支配者の視点と被抑圧者の視点の両方から物事を見て、両方の視点を捉えることができる能力ともみなすことができる。
しかし、すべての女性がまったく同じ経験を持つわけではない。そのため、すべての女性に共通する単一のスタンドポイントは存在しない。ここからブラック・フェミニスト認識論が発展した。パトリシア・ヒル・コリンズはまず、ブラック・フェミニスト認識論の観念を導入し、それは人種差別と性差別の両方に対処する黒人女性の個人的経験から導かれると述べた。コリンズはこの認識論を用いて、自らの主体性を保持する力を黒人女性に与えようとする。彼女は黒人女性を「内側の外部者（outsiders within）」と表現する。これによって彼女が言おうとしているのは、黒人女性は自らが社会的にどこに置かれているかを内側から十分に経験してきた一方で、支配集団からは十分に距離を保っており、批判を提示することができる、ということである。
ヘイディ・サフィア・ミルザもまた、ブラック・フェミニスト・スタンドポイント理論についての分析を提示している。彼女によれば、新たな対話は、ブラック・フェミニスト女性の独自の視点から生み出される。ミルザは、黒人女性が時に「他者（the other）」と呼ばれることを認めたうえで、彼女たち独自の用語を提示し、彼女たちは人種・ジェンダー・階級の周縁の間にある「第三の空間（third space）」としての地位を持つ、と論じる。ミルザによれば、この空間には「公式の言語や言説は存在しない。だからこそ黒人女性は『能動的な主体（active agents）』の位置に置かれ、その視点を共有し、新たな洞察を提供する責任を負う」のである。
1990年代後半に至るまで、黒人女性が焦点となることは多くはなかった。黒人女性による作品や、黒人女性を扱った作品——映画および出版物の双方——が数多く現れ始めたのはこの時期である。これは、以前は支配的な集団による作品ばかりが出版や上映の対象となっていた過去からの、重要な転換を意味した。この時期以前で認められている黒人女性の作品は、19世紀初頭のものに限られる。今日比較的よく知られる著作としては、メアリー・プリンス（1831年）やメアリー・シーコール（1837年）のものがある。それらを除けば、次に注目される出版物はシルヴィア・ウィンター（1962年）とマリーズ・コンデ（1988年）まで待たねばならず、黒人女性による著作がほとんど存在しない120年以上の空白があった。この空白は、市場での位置において黒人女性がいかに無力であったかを示している。今日の社会において黒人女性による作品は増えつつあるものの、彼女たちの作品に対する支配力は依然として限定的であり、発言の機会や出版のためには一定の領域に限定されねばならない状況が続いている。


== 批判 ==
スタンドポイント・フェミニズムに対する批判はポストモダン・フェミニズムの側からもたらされており、知識を構築するための土台としての具体的な「女性の経験」は存在しない、と論じられている。言い換えれば、空間と時間を超えた女性たちの生はあまりに多様であり、その経験を一般化することは不可能だ、というものである。スタンドポイント・フェミニズムはこの批判をある程度取り入れてきた（下記参照）。


== 現代のスタンドポイント・フェミニズム ==
今日、多くのスタンドポイント・フェミニストは、女性たちを隔てる多くの差異のために、単一で普遍的な「女性の経験」を主張することは不可能だと認めている。性差別は真空のなかで生じるものではないため、それを他の支配体系との関連で捉え、「支配の網（matrix of domination）」のなかで人種差別、同性愛嫌悪、植民地主義、階級差別とどのように相互作用するかを分析することが重要である。
現代のスタンドポイント・フェミニストの理論は、「それは女性の経験から必然的に生じるものというより、関係論的なスタンドポイントである」と捉える（差異フェミニズムも参照）。近年スタンドポイント・フェミニストは、諸個人は状況や関係する相手によっては抑圧されているが、他の状況や相手との関係では特権化されている、と論じている。彼女らの目標は、抑圧的な権力構造に対抗するのにより正確でより有効な仕方で、女性と男性を複数の支配体系の内部に位置づけることにある。これはキリアーキーとも呼ばれる。この立場への批判の一つは、女性たちのあいだの多くの相違点にこれほど強く焦点を当てることは、女性たちを結び付けうるまさにその共通点を消し去ってしまう、というものである。もしそうであるならば、広範な基盤を持つフェミニスト共同体を作ろうとしたり、特定の政策について合意を築こうとしたりすることは困難になる。
