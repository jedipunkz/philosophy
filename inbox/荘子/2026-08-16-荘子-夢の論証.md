# 夢の論証

## Full Text

夢の論証（ゆめのろんしょう、英: dream argument）とは、夢を見るという行為が、現実と錯覚を区別するために頼っている感覚を完全には信頼すべきでないという予備的証拠を与えているという主張である。したがって、感覚に依拠するいかなる状態も、少なくとも注意深く検討し、それが本当に現実であるかを厳密に検証すべきだとされる。


== 概要 ==

夢を見ているとき、人は通常夢を見ていると気づかない。まれな場合には、夢の中にさらに別の夢が含まれることもあり——2つの夢が重なることになる。しかしながら、同時に2つの夢を見ていると気づくという行為自体が、第3の夢の状態が存在することを意味し、その状態の中から夢見る者は他の2つの夢を意識する。このことから哲学者たちは、いかなる時点においても自分が実際に夢を見ていないと確信することがそもそも可能なのか、あるいは永続的な夢の状態にとどまり覚醒という現実を経験することなく過ごすことが本当に可能なのかを問い続けてきた。
西洋哲学において、この哲学的難問はプラトン（『テアイテトス』158b-d）、アリストテレス（『形而上学』1011a6）、およびアカデメイア懐疑主義者たちによって言及されてきた。現在ではルネ・デカルトの『省察』に基づくものとして最もよく知られている。夢の論証は、最も著名な懐疑的仮説の一つとなっている。
東洋哲学では、このタイプの論証はしばしば「荘周の逆説」と呼ばれる：

酒を飲む夢を見た者は朝に泣くかもしれない。泣く夢を見た者は朝に狩りへ出かけるかもしれない。夢を見ているあいだはそれが夢だとは気づかず、夢の中で夢占いをしようとすることさえある。目覚めて初めてそれが夢だったとわかる。そしていつか大いなる目覚めが訪れ、これがすべて大きな夢だったとわかるだろう。しかし愚か者は目覚めていると信じ、せっせと事物を理解しようとし、あの者は君主、この者は下僕と呼ぶ——なんと鈍いことか！孔子もあなたも夢を見ている！そして私があなたが夢を見ていると言うとき、私も夢を見ている。このような言葉は「至大の詐欺」と呼ばれるだろう。しかし一万世代の後に一人の大賢者が現れ、その意味を知るだろう——それでもまるで閃光のように現れたかのようだろう。
瑜伽行唯識学派の哲学者世親（4〜5世紀）は、著作「唯識二十論」でこの論証に言及した。荘子の夢文化に惹かれたジャック・ラカンとその追従者たちは、荘周の夢に関する思想を精神分析学とイデオロギーの領域に応用した。
夢の論証は大乗仏教およびチベット仏教の哲学において重要な位置を占めるようになった。仏教における実在の一部の学派（例えばゾクチェン）は、知覚される現実を文字どおり非実在とみなす。チョーギャル・ナムカイ・ノルブはこう述べている。「本当の意味では、私たちが生涯に目にするすべてのビジョンは大きな夢のようなものだ……」この文脈で「ビジョン」という語は視覚的知覚だけでなく、音・におい・味覚・触覚を通じた知覚、および知覚された心的対象への精神操作も含む。


== シミュレートされた現実 ==

夢を見ることは、私たちの現実もまた幻影ではないかと問う者たちに跳躍台を与える。精神的に生成された世界が「現実の世界」であると心が騙されうるということは、少なくとも一種のシミュレーション現実が一般的な、それどころか毎夜起こる出来事であることを意味する。
世界がシミュレートされていないと主張する者も、少なくとも睡眠中の精神は現実と幻影を区別しようとする際に完全に信頼できる機制ではないということを認めざるをえない。


== 批判的議論 ==
かつて哲学者ジョン・ロックとトマス・ホッブズは別々に、デカルトの夢の論証についての説明を論駁しようとした。ロックは夢の中では痛みを経験できないと主張した。過去数十年に行われたさまざまな科学的研究は、夢の中での痛みは生じうるがごくまれであるという証拠を示し、ロックの主張に反証を与えた。哲学者のベン・スプリンゲットは、ロックなら火の中に踏み込む際の激烈な痛みは夢の中で火に踏み込む場合と比較できないと答えたかもしれないと述べた。ホッブズは、夢は不条理に陥りやすいが覚醒生活はそうではないと主張した。
多くの現代哲学者が夢懐疑論を詳細に論駁しようとしてきた（例えばStone（1984）を参照）。アーネスト・ソウザ（2007年）は著書の一章をこの主題に割き、夢の新理論を提示したうえで、その理論が懐疑論への新たな論証を提起すると主張しつつもこれを論駁しようとした。『徳認識論：適切な信念と反省的知識』の中で彼はこう述べている。「夢の中では私たちは本当に信じているのではなく、信じるふりをしているだけだ。」
ジョナサン・イチカワ（2008年）とネイサン・バランタイン＆イアン・エヴァンス（2010年）はソウザの提案した解決策への批判を提示した。イチカワは、夢の中と同様に覚醒生活における信念が真の信念であるかそれとも想像に過ぎないかを判別できない以上、私たちは目覚めているか夢を見ているかをやはり判別できないと論じた。
夢仮説はヴァルバーグの個人的地平線のような他の哲学的概念を展開するためにも用いられる。「これ」がすべて夢であったとしたら、この世界はその内側に何が存在することになるのか、という概念である。


=== 夢懐疑論 ===
ノーマン・マルコムは著書『夢見ること（Dreaming）』（1959年）の中で、夢を語る人々が「眠っている間に本当にこのような心象を持ったのか、それとも目覚めた時にそう感じられるだけなのか」は重要かというウィトゲンシュタインの問いを詳述した。彼は「私は眠っている」という文は無意味な表現であること、夢は覚醒時の印象から独立して存在することはできないこと、夢に基づく懐疑論は「過去形の……歴史的意味と夢語り的意味を混同することから生じる」（120ページ）と論じた。「私は今目覚めていることを知っているか？」と題した章では、目覚めていることを否定するのが不条理であるという単純な理由から「私は目覚めていることを知っている」と言う必要はないと論じた。
哲学者ダニエル・デネットはカセットテープ仮説と呼ばれる夢理論でこのアイデアを発展させた。彼は夢が実際の意識経験ではなく、睡眠から覚醒する際に浮かび上がる擬似記憶であると推測した。これらの擬似記憶は現実の夢体験に対応するものではなく、実際には起こらなかった経験の純粋な創作である。
哲学者ジェニファー・ウィントは明晰夢の心理学に基づいて夢懐疑論に反論し、夢を実際の想像的経験として捉える概念的枠組みを提示した。
