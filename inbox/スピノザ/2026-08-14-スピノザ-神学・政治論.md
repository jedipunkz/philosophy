## Full Text

『神学・政治論』（しんがくせいじろん、羅: Tractatus Theologico-Politicus、TTP）は、オランダの哲学者バールーフ・デ・スピノザ（1632年–1677年）が1670年にラテン語で著し、匿名で刊行した哲学書である。本書は近世における最も重要かつ論争的な著作の一つであり、その目的は「個人を迷信および教会の権威への隷属から解放すること」にあった。本書においてスピノザは、当時のユダヤ教および西方キリスト教に対する見解を展開し、聖書、とりわけヘブライ語聖書を批判的に分析している。
本書は「ヨーロッパ知性史における最も重要な出来事の一つ」と評価されており、自由主義・世俗主義・民主主義に関する諸観念の基礎を築いた。スピノザは国家と宗教がとるべき最良の役割について論じ、アムステルダムのように、理性の範囲内で国家が至高性を保ちつつ、一定の民主主義と表現の自由・信教の自由を認めることが最善であると結論づけている。国家の目的は市民の自由を保証することにある。宗教指導者は政治に干渉すべきではないとされる。
スピノザは主著『エチカ』の執筆を中断し、ネーデルラント連邦共和国で高まる不寛容に対応するかたちで本書を書き上げ、宗教的権威および思想の自由に対する彼らの権力に直接に挑戦した。厳しい批判と、宗教指導者や保守派世俗権力による著作の全面的な抑圧の試みを正しく予期し、彼はラテン語で匿名出版し、オランダ語訳の出版は差し止めた。ある匿名の批判者は本書を「背教者たるユダヤ人が悪魔と共謀して地獄で鍛え上げた書」と評した。


== 歴史的背景 ==

17世紀半ばのネーデルラント連邦共和国の誇り高き宗教的寛容は、緊張状態にあった。貿易と帝国的支配権を巡るイングランドとの戦争は、北部ネーデルラントの繁栄に影響を及ぼした。
保守的なオランダ改革派の指導者たちは、市民当局に対して、彼らが反対する思想の流通や表現の自由の制限を圧力によって求めた。政治の領域においては、保守派はオラニエ家の一員による総督（スタットハウダー）、すなわち元首の地位の復権を求めた。第一次総督不在期（1650年–1672年）の間、ヨハン・デ・ウィットが事実上の元首として機能し、宗教的寛容政策を支持しており、これが繁栄を後押ししていた。ユダヤ人は公然と自らの宗教を実践することができ、商業部門の不可欠な一員となっていた。
また、共和国の宗教的・知的醸成に寄与した多数のキリスト教諸派も存在した。宗教的権威および宗教そのものに対して公然と挑戦を始めた反対者もあり、スピノザ自身がその一人であって、そのために1656年にアムステルダムのユダヤ人共同体から破門された。
同じ志を持つ友人であり、知的にも共鳴したアドリアーン・クールバッハ（1633年–1669年）は、宗教を痛烈に批判する2冊の著作を刊行した。これらはラテン語ではなくオランダ語で書かれていたため、はるかに広い読者層に届いてしまい、たちまち宗教当局の注目を集めて逮捕・投獄され、獄中で早くに死去した。彼の死はスピノザにとって大きな打撃であり、その反応として1665年に『神学・政治論』となる著作の執筆を開始した。
オランダ語で執筆することの危険を顧みて、スピノザの本書はラテン語で書かれている。『エチカ』の緻密な本文とは異なり、『神学・政治論』ははるかに親しみやすく、形而上学ではなく宗教と政治を扱っている。研究者たちは、『神学・政治論』の本文には、1656年の破門後にスペイン語で書いた弁明書が組み込まれているのではないかと示唆している。


== 執筆と刊行の経緯 ==

スピノザは主著『エチカ』の執筆に取り組んでいたが、それを脇に置いて『神学・政治論』を執筆した。数学的証明の形をとった『エチカ』の抽象的な構成とは異なり、『神学・政治論』はより論述的で、ラテン語の読者にとって親しみやすい。彼はネーデルラントで自身のもとを訪ねた王立協会の書記ヘンリー・オルデンバーグに手紙で新著について伝え、書簡による交流を続けた。オルデンバーグは驚いたが、スピノザは形而上学からの逸脱の理由を書き綴った。『神学・政治論』は、聖書に裏打ちされた神学者たちの権力に対する正面攻撃であった。スピノザは無神論の嫌疑から自らを弁護しようとしたのであり、宗教的権威に妨げられずに哲学する自由を求めたのである。
本論考は1670年にアムステルダムのヤン・リーウェルツによって匿名で刊行された。著者と出版者を政治的報復から守るために、扉には出版地としてハンブルクが、出版者として1605年に死去していたヘンリクス・キュンラートの名が記された。スピノザは当時のヨーロッパの学者たちの言語であった新ラテン語で執筆した。共和国内の学者以外の読者層にも届けるべく、次の段階としてオランダ語での刊行が計画されていた。スピノザのオランダ語訳者であり、コレヒアントの自由思想家でもあったヤン・ヘンドリクス・グラーゼマーカーは1671年までに版を準備し、出版者に送付したが、当該訳がスピノザとその支持者たちを当局によりいっそう危険な立場に置きうるため、スピノザ自身が印刷を差し止めた。

== 宗教の取り扱い ==
本論考においてスピノザは、ユダヤ教批判、ならびに一般的な組織宗教への、彼の最も体系的な批判を提示した。スピノザは、神学と哲学は分離されなければならず、とりわけ聖書の読解においてそうでなければならないと論じた。彼によれば、神学の目的は服従にあるのに対し、哲学は理性的真理の理解を目的とする。聖書は哲学を教えるものではなく、したがって哲学と一致させることはできない。そうすれば聖書の意味が歪められてしまう。逆に、理性が聖書に従属させられるならば、スピノザによれば「はるか昔の一般民衆の偏見……が理解を掌握し、これを暗くしてしまう」ことになる。
スピノザは、超自然的とされる出来事、すなわち予言や奇跡には自然的説明しか存在しないと考えた。彼は、神は神自身の本性の法則によってのみ働くと論じ、神が特定の目的（テロス）のために働くという見解を退けた。スピノザにとって、神が何らかの特定の目的のために働くと信じる者は妄想に囚われており、自らの希望と恐怖を自然の働きに投影しているのである。


== 聖書の解釈 ==
スピノザは近代形而上学・道徳哲学・政治哲学の父であるのみならず、ヘブライ語聖書のいわゆる高等批評の父でもあった。彼は解釈という観念に特に鋭い関心を寄せており、あらゆる組織的宗教はそれぞれの特定の解釈を制度化された仕方で擁護しているにすぎないと感じていた。彼は、キリスト教で「モーセ五書」（ペンタテウク）、ユダヤ教で「トーラー」と呼ばれるヘブライ語聖書の最初の5書について、そのモーセ執筆説という前提を全面的に退けた。彼はヘブライ語聖書の構造を分析し、それが本質的に多数の著者と多様な起源をもつ編纂された本文であることを示した。彼の見解では、それは一度に「啓示された」ものではなかった。
『神学・政治論』は、ユダヤ教聖書を正しく理解するならば、力によって一切の異議を封じようとする聖職者の戦闘的な不寛容には何の権威も与えられないことを示すべく企てられた。この目的を達成するために、スピノザは聖書の適切な理解が何を意味するかを示さねばならず、そこから聖書に批判を適用する機会が生じた。そのアプローチは、ジョン・バニヤン、メナセ・ベン・イスラエルおよび戦闘的な聖職者といった同時代人のそれとは著しく対照的であった。自然に対して超自然的な競合相手を、また国家の市民政府に対して競合する権威を、いずれも許さなかったスピノザは、聖書のテクストが、歴史的であると主張する他のいかなる文書とも全く異なる仕方で扱われるべきであるという主張のすべてをも退けた。聖書は「部分的に不完全で、腐敗しており、誤りに満ち、自己矛盾を含んでおり、我々はそのごく一部の断片しかもっていない」という彼の主張は、当時大きな嵐を巻き起こし、少なくとも1世紀にわたって彼の悪しき評判の主因となった。それにもかかわらず、多くの人々は次第に彼の見解を受け入れ、真の「神の言葉」あるいは真の宗教は書物に記されたものではなく「人の心と精神に刻まれたもの」であるという彼の主張に同意するようになった。多くの学者や宗教指導者は今日、人間の思考と行為の進歩的発展における一流の重要性を持つ文書として聖書を正しく解釈するというスピノザの功績を称賛している。


== ユダヤ教の取り扱い ==
スピノザは1656年、それまで育ってきたイェシーバーで教育を受けたアムステルダムのユダヤ人共同体から永久に破門された。追放後、彼は共同体に戻ろうとはしなかった。『神学・政治論』において彼は自らをユダヤ人として言及することはないが、少なからぬキリスト教徒が彼をそう呼んだ。彼は「ヘブライ人」あるいは「ユダヤ人」について常に三人称で語っている。彼のヘブライ語の知識、イェシーバーでのユダヤ教聖書研究、および宗教当局が聖典についての特殊な知識を主張して権力を行使する仕組みへの内部からの知識は、思想の自由の擁護対象としてユダヤ教を彼にとって顕著な対象たらしめた。
本論考はユダヤ人を選民とする観念を退けた。スピノザにとってあらゆる民族は互いに対等であり、後に自由主義と呼ばれるものの中核的要素を明確に述べたのである。神は一者を他者の上に引き上げてはいない。
スピノザはまた、ユダヤ人が絶えざる迫害に直面しながら、なぜユダヤ民族がかくも長く生き残ってきたのかについて、社会学的説明を示した。彼の見解では、ユダヤ人は異邦人（ゴイム）の憎悪（すなわち反ユダヤ主義）とユダヤ人の分離主義との組み合わせによって存続してきたのである。
さらに彼は、ユダヤ人の存続にとってもう一つ決定的な理由を挙げた。それは、彼の見解では民族の存続を永続的に維持するのに十分なものであり、ブリット・ミラー（割礼）であった。それは身体に印を刻むという人類学的表現の究極形態であり、究極の識別子として機能する、分離性の目に見える象徴であった。
スピノザはまた、トーラーについて新奇な見解を提示した。それは本質的には古代イスラエル国家の政治的憲法であると論じたのである。彼の見解では、この国家がもはや存在しない以上、その憲法もはや有効ではありえない。したがってトーラーは特定の時代と場所に適応したものであり、時代と状況が変化した以上、ユダヤ人にとって法的拘束力ある文書とはもはや見なしえないと主張した。


== スピノザの政治理論 ==
スピノザは、各人が自らの右腕のみに頼って自らを守らなければならないとすれば、人間の生は「厭わしく、粗野で、短い」ものになるだろうという点で、トマス・ホッブズと一致していた。真の人間的な生は、組織化された共同体、すなわち国家あるいはコモンウェルスにおいてのみ可能である。国家は生命・身体・財産の安全を保障し、個人が自ら生産することのできない多くの生活必需品を各人の手の届くところに置き、人間の諸能力のより高次の発達のために十分な時間とエネルギーを解放する。ところで国家の存立は、その成員あるいは市民の側での、統治する主権的権威に服従するという一種の暗黙の合意に依存する。国家においては、誰も好き勝手に振る舞うことは許されない。すべての市民は法に従う義務を負い、法を独自の仕方で解釈する自由すらもたない。これは一見、個人による自由の喪失と、彼らを支配する絶対権力の樹立のように見える。しかし、実際にはそうではない。第一に、組織化された国家の利点なしには、平均的な個人はあらゆる種類の危険や困難、そして自らの情念にさらされるので、いかなる真の意味においても、とりわけスピノザが用いた意味においても、自由と呼べるものではない。人間は、他者から自分を守るためだけでなく、自らの低次の衝動から身を守り、真に人間的である唯一の生である理性的生を送ることを可能にするためにも、国家を必要とする。第二に、国家の主権は真に絶対的なものではありえない。いかなる種類の統治もそれがないよりはましであるのは事実であり、平和を乱すよりは煩わしいことに耐えるほうがよいということになる。しかし、合理的に賢明な統治は、それ自身の利益のためであっても、不合理な措置を差し控えることによって市民の善意と協力を確保するよう努めるだろうし、平和的な手段を用いる限りにおいて、市民が改革を主張することを許容し、あるいは奨励さえするだろう。このようにして、国家は究極的には市民の統一された意志、後にルソー（彼はスピノザを読んだ）が「一般意志」と呼んだものの上に立脚しているのである。
スピノザは時に、国家はその臣民に対して絶対的な主権を認められるべきだと書いている。しかしそれは主として、国家に対するあらゆる種類の教会的支配への彼の断固たる反対に由来する。彼は一種の精神的接着剤として国家宗教と呼びうるものを支持する用意はあったが、彼のその宗教についての説明は、歴史的信条のいずれの信奉者にとっても、また理神論者・汎神論者、その他のあらゆる者にとっても、狂信的な信者ないし不信者でない限り、受け入れ可能なものとなっている。表向きは思想と言論の自由のために、スピノザは戦闘的教会の暴虐に効果的に抵抗するために、絶対的な主権に近いものを市民政府に委ねようとするのである。


=== 人間の力は精神と知性の強さにある ===
スピノザの政治理論において最も印象的な特徴の一つは、「権利すなわち力（right is might）」という彼の基本原理である。彼はこの原理を統治の問題全体に体系的に適用し、それによって政治理論を、あたかも応用数学を扱っているかのごとく科学的精神で扱うことができたことに、いくらか満足していたようである。権利と力の同一視あるいは相関付けは、多くの誤解を招いてきた。人々はスピノザが正義を粗暴な力に還元したと想定した。しかしスピノザはレアルポリティークを承認することからはほど遠かった。スピノザの哲学において「力」という語は（彼の道徳哲学から明らかであるように）、物理的な力よりもはるかに多くを意味する。『政治論』の終わり近くの一節において彼は、「人間の力は主として精神と知性の強さにある」と明言している。それは実際、人間のあらゆる能力と適性、とりわけそのうち最も高次のものから成るのである。正しく理解すれば、スピノザの哲学全体は、個人および共同体の生における理想的な動機のための十分な余地を残している。もっとも、伝記作家であるスティーヴン・ナドラーおよびジョナサン・I・イスラエルが指摘するように、スピノザは未完の『政治論（Tractatus Politicus）』において述べているとおり、男性のみを完全な市民とみなしている。


=== 君主制、貴族制、民主制 ===
スピノザは主要な国家の種類、すなわち主要な政府形態として、君主制・貴族制・民主制を論じている。それぞれに独自の特殊性と、国家の第一の機能を実現しようとするならば必要となる特別な保護策とがある。君主制は、独裁の試みを防ぐさまざまな憲法的制約に服さない限り、専制に堕しうる。同様に、貴族制は寡頭制に堕しうるので類似の制約を必要とする。全般としてスピノザは民主制を好み、それによって代議制政府のいかなる種類も意味していた。民主制の場合、共同体と政府は君主制や貴族制の場合よりも同一視されるので、民主制は人民と政府との頻繁な衝突を最も経験しにくく、したがって平和を確保し維持するのに最も適している。


== 受容と影響 ==
スピノザの『神学・政治論』が政治的な支持を受けたとは考えにくく、1672年のオランダ共和主義派の政務長官ヨハン・デ・ウィットの殺害以前にさえ、抑圧の試みがなされていた。1673年にはオランダ改革派のドルドレヒト教会会議によって公に糾弾され、翌年には公式に禁書となった。『神学・政治論』への厳しい批判は刊行後ほぼ即座に現れはじめた。最も早く、そして最も悪名高い批判の一つは、1670年のライプツィヒ大学教授ヤーコプ・トマジウスによるものであった。
これに対して、イギリスの哲学者G・E・ムーアはルートヴィヒ・ウィトゲンシュタインに対して、その著作の一つに、スピノザの本論考へのオマージュとして『Tractatus Logico-Philosophicus』と題するよう提案した。
