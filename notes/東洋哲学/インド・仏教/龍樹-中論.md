# 龍樹『中論』（根本中頌）

| 項目 | 内容 |
|---|---|
| 著者 | 龍樹（ナーガールジュナ、150–250年頃） |
| 著作 | 中論（正式名称『根本中頌』、梵: Mūlamadhyamaka-kārikā） |
| 成立 | 2〜3世紀、南インド |
| 地域 | インド、東洋哲学 |
| 分野 | 大乗仏教、中観派、仏教論理学 |
| 主題 | あらゆる事象・概念に自立的な実体（自性）が無いことを帰謬論証によって示し、徹底した相互依存性としての「縁起」と「空」を確立する。 |
| キーワード | 空、無自性、縁起、八不、二諦、四句分別、帰謬論証、中道 |

『中論』は、初期大乗仏教の僧・龍樹（ナーガールジュナ）による論書で、インド中観派の**根本典籍**である。正式名称は『根本中頌』（こんぽんちゅうじゅ）。中国三論宗、そしてチベット仏教が依用し、大乗仏教のほぼ全域に影響を及ぼした。本文は整った散文の論書ではなく、27章の**偈頌（詩文）**を連ねた極度に簡潔なテキストで、注釈なしには容易に読み解けない。そのため成立直後から膨大な注釈書の系譜を生み、注釈の違いがそのまま学派の分岐になっていった。

なお、伝統的に龍樹に帰せられる著作は多いが、近代仏教学において真作との見解が一致しているのは、この『中論（頌）』だけである。『中論』は龍樹の代表作であると同時に、龍樹という思想家を確定させる唯一の足場でもある。

## 龍樹という人物

龍樹の生涯を厳密に語れる史料は無い。インド原典のナーガールジュナ伝が現存せず、鳩摩羅什訳と伝わる『龍樹菩薩伝』の伝説的記述に頼るほかないためである。それによれば南インドのバラモンの家に生まれ、幼くしてヴェーダを諳んじたという。プトゥンの『仏教史』は、南方ヴィダルバのバラモン出身で、ナーランダー僧院でバラモンの学問を修めたのち出家したと伝える。サータヴァーハナ朝の保護下で各地からの僧のために僧院を営み、その地（ハイデラバード東方約70km）は後に**ナーガールジュナ・コーンダ**（龍樹の丘）と呼ばれた。

さらに事情を複雑にするのは、「ナーガールジュナ」という名に帰せられる仕事の幅の広さである。中村元は、ナーガールジュナ名義の著作群を、(1)『中論』など空思想の著者、(2)『大智度論』の著者、(3)『十住毘婆沙論』の著者、(4)『宝行王正論』など現実的問題を扱った著者、(5)真言密教の学者、(6)錬金術の学者、の6つに分類し、少なくとも(5)(6)は(1)とは色彩を異にする別人ではないかとした。大正期の河口慧海・寺本婉雅は、中観の祖を「古龍樹」、『八十四成就者伝』の密教的龍樹を「新龍樹」として分けるべきだと論じている（羽溪了諦のように、伝記の骨子が共通することから同一人物の潤色とみる反論もある）。インドでは仏教僧としてよりも錬金術師・占星術師として名高いが、これは後代の同名人物との混同とされる。

本ノートが扱うのは、このうち(1)——『中論』を著した中観派の祖としての龍樹である。

## 何を論駁した書か

『中論』は体系の構築書ではなく、**論駁の書**である。標的は、部派仏教、とりわけ当時最大勢力であった**説一切有部**のアビダルマ（論）だった。

釈迦の説いた縁起説は、部派仏教の時代に精緻な教理体系へと発展していく。その過程で説一切有部などは、生成変化する現象の背後に、それを成立させる要素として、変化しない固有の相をもつ形而上的・自立的な基体としての「**法**（ダルマ）」を想定するようになった（五位七十五法、三世実有・法体恒有）。中村元が『中論』を「論争の書」と呼び、その主要論敵を説一切有部としたのはこのためである。中観派はこうした論敵を「有自性論者」と総称した。

龍樹は、この「法」の実在視を、釈迦の本義から逸脱した**常見**（あるいはその裏返しの**断見**）への執着として斥ける。その進め方は整然とした体系的反駁ではなく、論敵の主張を一つずつ取り上げ、「その前提に立てば矛盾に陥る」と示していく**帰謬論証（プラサンガ、背理法）**の反復である。「モグラ叩き」のように地道に潰していくその積み重ねが、結果として「自立的なものは何ひとつない」という徹底した無自性の思想を浮かび上がらせる。

## 八不と27章の構成

冒頭の「帰敬序」には、全体の要旨として名高い**八不**が掲げられる。

> 不生不滅・不常不断・不一不異・不来不去

生も滅も、常も断も、一も異も、来も去も、いずれも成り立たない——対になる二項のどちらにも寄らないこと、それが本書の立場である。

続く27章は、仏教教理の主要概念をほぼ網羅し、そのすべてについて「非自立性」を帰謬論証していく。

| 章 | 考察の対象 |
|---|---|
| 第1章 | 原因（縁・四縁） |
| 第2章 | 運動（去来） |
| 第3–5章 | 認識能力（六根・六境）、集合体（蘊）、要素（界） |
| 第6章 | 貪り汚れることと、その主体 |
| 第7–8章 | 作られたもの（有為）の生・住・滅、行為と行為主体 |
| 第9–11章 | 過去存在、火と薪（アートマン・五取蘊の比喩）、始原と終局 |
| 第12–14章 | 苦しみ、形成されたもの（行）、集合 |
| 第15章 | 自性、および「有」と「無」 |
| 第16–17章 | 束縛と解脱（輪廻と涅槃）、業と果報 |
| 第18–21章 | アートマン、時（過去・現在・未来）、原因と結果、生成と壊滅 |
| 第22–23章 | 如来（修行者の完成形）、顛倒した見解 |
| 第24章 | 四諦 — 論敵の批判への反論と**二諦説** |
| 第25章 | 涅槃 |
| 第26章 | 十二支縁起 |
| 第27章 | 誤った見解の批判と総括 |

「原因」「運動」「時」「アートマン」といった一般的な形而上学の主題から、「四諦」「涅槃」「如来」という仏教の根幹まで、聖域を設けずに同じ論法をかける点が本書の徹底ぶりを示している。

## 新しい「縁起」と「無自性（空）」

この世のあらゆる事象・概念は、「陰と陽」「長と短」「因と果」「主体と客体」のように、対となるものに依存し、互いに限定し合うことで相対的に成り立っている。一方が欠ければ他方も成り立たない。したがって、それ自体で自立的・固定的に存在するもの（自性）はどこにもなく、すべては「**仮名**（けみょう）」＝言葉によって仮に設けられたものにすぎない。

この**相互依存性（相依性）**に焦点を当てた発想こそ、龍樹が「縁起」という語で捉え直したものである。釈迦の説いた縁起（時間的な因果の連鎖）が、ここで事象・概念間の相互限定性へと拡張されている。龍樹の「空」が「**無自性空**」と呼ばれるのはこのためだ。

重要なのは、この「空」がニヒリズムではないことである。空（śūnyatā）は「nothing（無・虚無）」ではなく「empty（空っぽ）」であり、万物が自立的な実体を持たないという事態を指す。実際『中論』は「有」も「無」も、常見も断見もともに否定している。中国道教の「無（虚無）」と混同されやすいが、別物である。

## 二諦説 ― 第24章の応答

徹底した相対化は、当然の帰結として釈迦自身の教えにも及ぶ。論敵はそこを衝いた。第24章冒頭（1–6節）に置かれるその批判は鋭い——「一切が空であるなら、四聖諦も四向四果も存在せず、三宝（仏法僧）も、世俗のあらゆる慣用・秩序・規則も破壊されてしまうではないか」。

龍樹の応答（7節以降）は二段構えである。まず7節で、論敵は「空の効用」「空そのもの」「空の意義」を知らないと指摘し、8–12節で**二諦**（satya-dvaya）を導入する。

- **世俗諦**（saṃvṛti-satya） — 言語・概念によって捉えられた世間的な真理。分別智の領域。
- **勝義諦**（paramārtha-satya、第一義諦・真諦） — 概念と言語を離れた究極の真理。無分別智の領域。

自分が示しているのは釈迦が悟った深遠な真理（勝義諦）であり、それは世俗諦を破壊するどころか**基礎づけてすらいる**。むしろ「空」「無自性」を否定する有自性論者のほうが、縁起も存在も果報も成り立たなくしている——13–40節はこの反転した主張の展開である。

この二諦の枠組みによって、「釈迦の教えは方便として世俗の言葉で説かれた」という解釈の余地が開かれ、大乗が伝統教理を否定せずに乗り越えるための理論装置が与えられた。以後、二諦は東アジア仏教でも繰り返し再解釈されることになる（三論宗の吉蔵は古来十四の異説があるとし、天台宗は七種の二諦を立て、浄土真宗は意味を転用して信仰を真諦・世間道徳を俗諦とした）。

## 涅槃と戯論の寂滅

終盤の3章は、批判の書を実践の書へと着地させる。第25章は、真の涅槃とは一切の分別・**戯論（けろん）**が滅した境地に他ならないと説く。第26章は、それこそが古典的な十二因縁の「無明」を消し、苦滅へ向かう「逆観」を成立させるものだとして、自説を釈迦の縁起説へと接続する。そして第27章で常住をめぐる諸説を再度批判しつつ総括し、釈迦を讃えて全体を締めくくる。

論破のための論破ではなく、言語と概念による世界の固定化（戯論）を解体することが、そのまま解脱の道である——これが『中論』の実践的な骨格である。

## 四句分別という道具

龍樹の論法を支えるもう一つの道具が**四句分別**（catuṣkoṭi）である。ある命題 P について「是（P）」「非（¬P）」「亦是亦非（P かつ ¬P）」「非是非非（そのいずれでもない）」の四つの可能性を網羅的に立て、そのすべてを否定する（四句否定）。これによって、言語的・論理的な概念化そのものを超えた「空」が顕わになるとされる。

この形式自体は仏教以前に遡り、リグ・ヴェーダ第10巻のナーサディーヤ讃歌（宇宙の起源を「存在する／存在しない／存在しかつ存在しない／いずれでもない」と問う）にその原型が見える。龍樹はこれを、釈迦の**十四無記**（形而上学的問いへの沈黙）の手法を継ぐものとして論理的に徹底させた。

現代の論理学者はこれを単なる矛盾ではなく、矛盾許容論理や多値論理の先駆と読む。グレアム・プリーストは四句分別を四値論理と解釈し、さらに空を扱うための値 e を加えた五値へ拡張して勝義諦の記述を試みている。ただし「空」を論理値として操作する扱いは、空に自性を認めないという仏教本来の立場とは整合しない、という指摘もある。

## 「中道」の一偈と解釈の分岐

『中論』中に「中道」という語が現れるのは、**第24章第18偈のただ一箇所**にすぎない。にもかかわらず、この一偈が東アジア仏教の方向を決めた。鳩摩羅什はこれを次のように訳した。

> 衆因縁生の法、我即ち是れ無なりと説く。亦た是れ仮名と為す。亦た是れ中道の義なり。

中国ではこの詩句が多少の変更を経て伝えられ、天台宗の祖とされる慧文禅師がこれに着目し、空・仮・中の**三諦**を示すものとして読んだ（三諦偈）。ここから天台智顗の三観説（空観・仮観・中観）が立てられ、中諦を第一義諦とする独自の教学が展開していく。

しかし中村元は、『中論』の原文とチャンドラキールティの注釈に即して検討した結果、この偈の原意は「縁起・空・仮名・中道の4つが同趣意である」と説いたものにほかならず、天台宗や三論宗が説いたような「空をさらに空じた境地に中道が現れる」という構図ではなかったと結論している。東アジアの中観理解が、龍樹の原意からどこで分岐したかを示す論点である。

なお「中観」という漢語自体、インドにはない呼称である。原語 Mādhyamika は「中を理解する者」「中道論者」の意で、「観」に相当する部分をもたない。三論宗の吉蔵が羅什訳『中論』を『中観論』と呼び、注釈書『中観論疏』を著したのが「中観」という呼び名の始まりとされる。

## 注釈書の系譜と学派の分裂

『中論』が偈頌だけの簡潔なテキストであったことは、注釈の伝統を生んだ。伝・龍樹自註の『無畏論』、ブッダパーリタ（仏護）の『根本中論註』、バーヴァヴィヴェーカ（清弁）の『般若灯論』、チャンドラキールティ（月称）の『浄明句論』、漢訳では青目（ピンガラ）の注釈が代表である。

6世紀初頭、仏護と清弁は空の**論証方法**をめぐって袂を分かった。清弁は唯識派の陳那の論理学・認識論を取り入れ、積極的な論証を構築したが、月称らはこれを批判する。仏護の系譜は**プラーサンギカ（帰謬論証派）**、清弁の系譜は**スヴァータントリカ（自立論証派）**と呼ばれ、前者はとくにチベットで重視された。8世紀にはジュニャーナガルバ・シャーンタラクシタ（寂護）・カマラシーラ（蓮華戒）らが唯識説を空の理解への段階として肯定的に取り込み、**瑜伽行中観派**（後期中観派）を形成する。11世紀のアティーシャは唯識と中観を統合する「大中観」を称した。

## 東アジアとチベットへの伝播

**中国・日本** — 『中論』と『十二門論』、そして弟子・提婆（アーリヤデーヴァ）の『百論』が鳩摩羅什によって漢訳され、この三論に基づく**三論宗**が成立した。大成者は吉蔵（549–623）。日本には吉蔵の弟子・慧灌が625年に伝え、南都六宗の一派となったが、平安末には密教と融合して衰えた。天台宗の空・仮・中の三諦円融や一心三観も『中論』『大智度論』に基づく。中村元は、龍樹『十住毘婆沙論』の浄土教関係の部分（巻第五「易行品」）が後世の浄土教の重要な支えとなり、密教もまた龍樹の思想の延長上に位置づけうるとしている。日本の浄土真宗が龍樹を七高僧の第一祖に置くのは、この「易行品」ゆえである。

**チベット** — チベット仏教と中観派の関係は、思想面にとどまらず人的にも深い。吐蕃のティソン・デツェン王に招かれたシャーンタラクシタはチベット初の僧院サムイェー寺を建て、その弟子カマラシーラは中国禅僧・摩訶衍との論争（サムイェー寺の宗論）に勝ってチベット仏教の方向を決定づけた。後にグゲ王国が招請したアティーシャの顕密統合志向が現在のチベット仏教の雛形となり、ツォンカパがブッダパーリタの注釈によって帰謬派的な中論理解に確信を得て、これを確立する。チベット仏教の密教面の柱が無上瑜伽タントラだとすれば、顕教面の柱は中観派の著作と思想である。

## 近現代の評価

『中論』の論法は、古代から評価が割れてきた。説一切有部からは「都無論者」（一切が無であると主張する者）と呼ばれ、同じ大乗の瑜伽行派からも、スティラマティに「一つの極端説に固執する極端論」、ダルマパーラに「非有を執している」と評された。「気味の悪い破壊的な議論をなす虚無論者」という評は古代インドで既に一般的だったという。

近現代の比較思想では、次のような読みがなされている。

- **否定神学との近似** — 中村元は、「縁起」「空」の思想を新プラトン主義、とりわけ偽ディオニュシオス・アレオパギテースらの否定神学に比較的近いものとして挙げた。ただし西洋では、アリストテレス的な実体論が主流であったため、この種の発想は神秘主義のなかの傍流にとどまったとする。
- **実体批判の系譜** — 中村元は、事象の相互依存によって空を理論的に基礎づけた龍樹に対応する西洋の議論として、バートランド・ラッセルの〈実体〉批判を挙げている。
- **慈悲の基礎づけ** — 空をニヒリズムと見る批判は絶えないが、排斥も対立もない真の基底の獲得が生きとし生けるものへの肯定・慈悲につながり、実践を基礎づけるという評価がある。神概念が包括性を担保して他者への愛につながるキリスト教と、構成的には類似するという見方である。
- **現代英語圏の研究** — Jan Westerhoff は般若経典のアビダルマ批判と「包括的な仮象論」を軸に中観を再構成し（*Madhyamaka*, 2018）、Bronwyn Finnigan は空の思想が体系的な倫理的区別と両立するかを論点として整理している（*Madhyamaka Ethics*, 2018）。Douglas Duckworth は中観と唯識を存在論と現象学の対比として読み解き（2019）、Roy Sorensen は「究極の基底が存在するという前提」自体を疑う認識論として龍樹を扱う（*Nothing*, 2022）。

| 八不 | 不生不滅・不常不断・不一不異・不来不去。二辺のいずれにも寄らない立場の標語 |
| 二諦 | 世俗諦（言語・概念による真理）と勝義諦（概念を離れた究極の真理）の区別 |
| 四句分別 | 是・非・亦是亦非・非是非非の四項をすべて否定し、概念化を超える論理形式 |
| 帰謬論証（プラサンガ） | 論敵の前提に立てば矛盾に陥ることを示す背理法。『中論』の主たる論法 |
| 戯論（prapañca） | 言語と概念による世界の固定化。その寂滅が涅槃とされる |
| 仮名（けみょう） | 事物が言葉によって仮に設けられたものにすぎないこと |

## 位置づけ

『中論』以後、「空」は大乗仏教の中心的課題となり、中観派という一大学派が生まれ、その思想は三論宗・天台宗・禅宗・チベット仏教へと分岐していった。釈迦の「無我」「縁起」を論理的極限まで押し進め、形而上学的実体をことごとく解体してみせたという意味で、本書は仏教思想史の分水嶺にあたる。

同じ仏教思想でも、本ノートと並ぶ `notes/東洋哲学/インド・仏教/中村元-ブッダのことばスッタニパータ.md` が最古層の実践的な生き方の教えを伝えるのに対し、『中論』はその教えを支える存在論を徹底的に反省した理論書である。また `notes/東洋哲学/日本/親鸞-顕浄土真実教行証文類.md` の親鸞は、龍樹を七高僧の第一祖として仰ぐが、そこで依拠されるのは『中論』ではなく『十住毘婆沙論』「易行品」であり、同じ龍樹が空の論理家としてと、易行道の祖としてと、二つの顔で東アジアに受容された経緯がうかがえる。
